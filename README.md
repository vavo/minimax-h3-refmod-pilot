# RefMod Pilot

ComfyUI workflows for MiniMax H3 character references, by LoRA Pilot.

## Status

Initial repository setup. The workflow kit is being prepared and tested; no release is available yet.

Planned contents:

- A simple character RefMod creator workflow.
- A matching multi-character video workflow.
- Photo-selection guidance, setup instructions and tested dependency versions.

RefMods store reusable reference latents. Creating them does not train a LoRA or fine-tune H3 model weights.

## Built on

The workflows use [ComfyUI](https://github.com/Comfy-Org/ComfyUI) and [ComfyUI-MiniMaxH3Mod](https://github.com/Luisacaotica/ComfyUI-MiniMaxH3Mod) by Luisacaotica. RefMod Pilot provides workflow configuration and usability guidance; the underlying RefMod implementation comes from that upstream project.
